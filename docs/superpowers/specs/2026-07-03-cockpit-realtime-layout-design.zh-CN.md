# 驾驶舱实时布局改版设计

## 背景

当前 `tracertmonitor` 驾驶舱是演示版，页面没有完全铺满视口，右下角存在空白；底部“路径级监控”区域过矮，只显示汇总文本，不能表达“持续监测中每条路径状态随时间变化”的核心场景。

## 范围

本次只改前端驾驶舱体验，不接入真实域名/IP 探测数据流。数据仍来自 demo 会话，但浏览器端会模拟持续采样，让 UI 以真实监测形态刷新。

## 设计

页面采用固定全屏驾驶舱布局：顶部为目标和操作栏，中间为问题路径、拓扑、路径详情三列，底部为全宽实时路径监控区。网格不再留下未占用单元，所有面板都在 `100vw` 与 `100vh` 内铺满。

底部每条路径渲染为一张折线监控卡：展示窗口占比、平均 RTT、丢包率、Jitter，并绘制 RTT 曲线和丢包点。鼠标悬停折线图时显示该时间点的具体数值。浏览器端每隔几秒推进一次 demo 观测数据，重新计算当前窗口并刷新拓扑、详情和折线图。

## 验收

- 页面根容器铺满整个视口，没有右下角空洞。
- 底部路径监控区域高度足够，所有路径卡片可以完整展示或在区域内滚动。
- 每条路径有可视化折线图，能显示 RTT 曲线和丢包点。
- UI 自动刷新，模拟持续监测状态。
- 静态资产测试能防止实时监控区和全屏布局被误删。
